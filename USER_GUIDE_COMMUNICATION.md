# Guide Utilisateur - Nouveaux Flux de Communication

## 📱 Guide Complet pour Clients et Réparateurs

### Pour les **CLIENTS** 🚴

#### 1️⃣ Créer une Demande de Réparation

1. **Connectez-vous** à votre compte client
2. Allez au **Dashboard**
3. Cliquez sur l'onglet **"Create Repair"**
4. Remplissez le formulaire:
   - **Title**: Titre court de la réparation (ex: "Chaîne cassée")
   - **Description**: Détails du problème (ex: "La chaîne a cassé lors d'une sortie")
   - **Bike Type**: Type de vélo (VTT, Route, Ville, etc.)
   - **Location**: Où la réparation doit avoir lieu

5. Cliquez sur **"Create Repair Request"**
6. ✅ Votre demande est créée et visible par les réparateurs!

#### 2️⃣ Consulter les Offres Reçues

1. Allez au **Dashboard**
2. Cliquez sur l'onglet **"Offers Received"**
3. Vous verrez tous les réparateurs qui ont soumis une offre pour votre demande

**Pour chaque offre, vous voyez:**
- 👤 Nom du réparateur
- 💶 Prix estimé
- ⏱️ Durée estimée (en heures)
- 💬 Message du réparateur

#### 3️⃣ Accepter ou Rejeter une Offre

**Pour accepter:**
1. Consultez les offres reçues
2. Trouvez l'offre que vous préférez
3. Cliquez sur le bouton **"Accept Offer"**
4. ✅ L'offre est acceptée - vous pouvez entrer en contact avec le réparateur!

**Pour rejeter:**
1. Cliquez sur le bouton **"Reject"**
2. Cette offre disparaît de votre liste

**💡 Conseil**: Vous pouvez accepter plusieurs offres et comparer les prix/délais avant de choisir la meilleure!

---

### Pour les **RÉPARATEURS** 🔧

#### 1️⃣ Explorer les Demandes Disponibles

1. **Connectez-vous** à votre compte réparateur
2. Allez au **Dashboard**
3. Cliquez sur l'onglet **"Explore Repairs"**
4. Vous verrez toutes les demandes de réparation disponibles!

**Le système affiche automatiquement:**
- Les demandes dans un rayon de **20 km** autour de vous (si vous avez une localisation)
- Les demandes les plus récentes en premier

#### 2️⃣ Soumettre une Offre

1. Trouvez la demande qui vous intéresse
2. Cliquez sur le bouton **"Submit Offer"**
3. Un formulaire s'affiche où vous pouvez:
   - **Your Quote (EUR)**: Entrez votre prix (ex: 45.50)
   - **Estimated Duration (hours)**: Durée estimée (ex: 1 heure)
   - **Message to Client**: Expliquez votre approche/pourquoi vous êtes le meilleur choix

4. Cliquez sur **"Send Offer"**
5. ✅ Votre offre est envoyée au client!

**💡 Conseil**: Écrivez un message personnalisé pour augmenter vos chances d'être choisi!

#### 3️⃣ Gérer Vos Offres

1. Allez au **Dashboard**
2. Cliquez sur l'onglet **"My Offers"**
3. Vous verrez toutes vos offres organisées par statut:

**Pending** (En attente):
- Le client n'a pas encore répondu
- Vous pouvez attendre ou soumettre d'autres offres

**Accepted** (Acceptée):
- 🎉 Félicitations! Le client a accepté votre offre
- Vous pouvez maintenant entrer en contact avec le client
- Allez au **Message** pour discuter des détails

**Rejected** (Rejetée):
- Le client a refusé votre offre
- Pas grave! Il y a d'autres demandes à explorer

## ⭐ Bonnes Pratiques

### Pour les Clients:

1. **Soyez précis** dans votre description
   - Plus les détails sont clairs, plus les réparateurs peuvent vous faire une offre juste

2. **Comparez les offres**
   - Ne choisissez pas toujours le moins cher
   - Regardez aussi l'expérience du réparateur (voir future système de notation)

3. **Acceptez rapidement**
   - Les réparateurs peuvent annuler après quelques jours d'inactivité
   - Plus vite vous acceptez, plus vite on commence!

4. **Donnez un avis** après la réparation
   - Cela aide les réparateurs à améliorer leur service

### Pour les Réparateurs:

1. **Tarifs compétitifs**
   - Recherchez les prix du marché local
   - Évitez de trop baisser vos prix

2. **Messages personnalisés**
   - "Bonjour, je peux réparer votre chaîne rapidement avec des pièces neuf garanties" ✅
   - "Ok offre" ❌ (trop court!)

3. **Localisation à jour**
   - Mettez à jour votre localisation dans le profil
   - Le système filtre par proximité (20 km)

4. **Répondez rapidement**
   - Les clients appécient une réponse rapide
   - Plus vite vous réagissez, plus vite vous avez du travail!

## 🔐 Sécurité et Confidentialité

- ✅ Les offres ne sont visibles que par le client concerné
- ✅ Votre numéro de téléphone n'est pas partagé automatiquement
- ✅ Tous les messages sont chiffrés en transit
- ✅ Vous pouvez bloquer un utilisateur à tout moment

## ❓ Questions Fréquentes

**Q: Combien d'offres puis-je soumettre pour une demande?**
A: Une seule! Vous ne pouvez pas envoyer plusieurs offres pour la même demande.

**Q: Puis-je modifier mon offre après l'avoir envoyée?**
A: Pas encore (prochaine version). Soyez sûr avant d'envoyer!

**Q: Que se passe-t-il si je rejette une offre?**
A: Elle devient invisible mais le réparateur verra le statut "rejected".

**Q: Puis-je accepter plusieurs offres?**
A: Oui! Mais nous recommandons d'en choisir une seule. Les futures versions rejetteront automatiquement les autres.

**Q: Comment entrer en contact après acceptation?**
A: Via la page Messages. Les détails de contact s'affichent.
