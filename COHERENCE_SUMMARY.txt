## 🔴 PROBLÈME CRITIQUE À CORRIGER IMMÉDIATEMENT

### userModel.js - Mauvais chemin d'import du pool

**Fichier**: `backend/models/userModel.js` ligne 1
**Problème**: 
```javascript
const pool = require('../db/db');  // ❌ MAUVAIS
// Devrait être:
const pool = require('../config/db');  // ✓ CORRECT
```

**Impact**: 
- Le model ne peut pas accéder à la base de données
- Les fonctions `findUserByEmail()` et `createUser()` échoueront

**Fix**: Changer le chemin d'import
