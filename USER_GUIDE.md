# 📘 Guide utilisateur - Plateforme Vélo

## 🎯 Introduction

Bienvenue sur la plateforme de mise en relation entre propriétaires de vélos et réparateurs professionnels. Ce guide vous aidera à profiter pleinement des nouvelles fonctionnalités.

---

## 👤 Pour les clients (propriétaires de vélos)

### 1️⃣ Créer une demande de réparation

1. Cliquez sur **"Nouvelle demande"**
2. Renseignez :
   - Titre de la réparation
   - Description détaillée du problème
   - Type de vélo
   - Localisation
   - Photos (optionnel mais recommandé)
3. Validez → Votre demande passe au statut **📝 Créée**

### 2️⃣ Recevoir et comparer les offres

**Quand vous recevez des offres** :
- Votre demande passe automatiquement au statut **⏳ En attente**
- Un badge **💼** s'affiche avec le nombre d'offres reçues
- Couleur du badge :
  - 🔵 Bleu : 1-2 offres
  - 🟠 Orange : 3-4 offres
  - 🟢 Vert : 5+ offres

**Comparer les offres** :
- Cliquez sur votre demande dans la liste
- Les offres s'affichent à droite
- Utilisez les **filtres et tri** :
  - **Trier par prix** : Trouvez la moins chère ou la plus premium
  - **Trier par durée** : Privilégiez la rapidité
  - **Trier par date** : Voyez les plus récentes

**Chaque offre affiche** :
- 💰 Prix proposé
- ⏱️ Durée estimée (heures)
- 📅 Date d'intervention proposée
- 💬 Message du réparateur
- ✅ Compatibilité avec votre type de vélo

### 3️⃣ Accepter une offre

1. Cliquez sur **"Accepter"** sur l'offre choisie
2. ✅ Notification : "Offre acceptée !"
3. **Automatiquement** :
   - Votre demande passe au statut **👤 Assignée**
   - Toutes les autres offres sont **rejetées**
   - Les réparateurs concernés sont notifiés
4. Le réparateur peut maintenant démarrer la réparation

### 4️⃣ Suivre la réparation

**Statuts de votre demande** :
- 📝 **Créée** : En attente d'offres
- ⏳ **En attente** : Offres reçues, en cours de comparaison
- 👤 **Assignée** : Réparateur choisi, en attente de démarrage
- 🔧 **En cours** : Réparation en cours par le réparateur
- ✅ **Terminée** : Réparation finalisée

**Actions disponibles** :
- **Pendant "Créée" ou "En attente"** : Vous pouvez annuler (❌)
- **Pendant "En cours"** : Vous pouvez finaliser la réparation (✅)

### 5️⃣ Finaliser

1. Quand le réparateur a terminé, cliquez sur **"✅ Finaliser"**
2. Votre demande passe au statut **✅ Terminée**
3. La demande reste visible dans votre historique

### 🎛️ Filtres et organisation

**Filtrer vos demandes** :
- **Tous** : Voir toutes vos demandes
- **Créée** : Nouvelles demandes sans offres
- **En attente** : Demandes avec offres à comparer
- **Assignée** : Demandes assignées à un réparateur
- **En cours** : Réparations en cours
- **Terminée** : Historique des réparations

**Trier** :
- **Plus récente** : Demandes les plus nouvelles en premier (défaut)
- **Plus ancienne** : Ordre chronologique inversé
- **Titre (A-Z)** : Tri alphabétique

## 🔧 Pour les réparateurs

### 1️⃣ Explorer les demandes disponibles

1. Accédez à **"Explorer les demandes"**
2. Consultez toutes les demandes en statut **Créée** ou **En attente**
3. Chaque demande affiche :
   - Titre et description
   - Type de vélo
   - Localisation
   - Photos
   - Badge **💼** (nombre d'offres déjà soumises)

### 2️⃣ Soumettre une offre

1. Cliquez sur une demande qui vous intéresse
2. Remplissez le formulaire d'offre :
   - 💰 **Prix** : Montant en euros
   - ⏱️ **Durée** : Temps estimé en heures
   - 📅 **Date d'intervention** : Début et fin proposés
   - 💬 **Message** : Expliquez votre approche
3. Cliquez sur **"Soumettre l'offre"**
4. ✅ Notification : "Offre soumise avec succès"

**Important** :
- Vous ne pouvez soumettre qu'**une seule offre par demande**
- Si la demande était en statut **Créée**, elle passe automatiquement en **En attente**

### 3️⃣ Suivre vos offres

**Voir vos offres** :
- Section **"Mes offres"**
- **Filtrer par statut** :
  - 💼 **Proposée** : En attente de réponse du client
  - ✅ **Acceptée** : Client a accepté votre offre
  - ❌ **Rejetée** : Client a choisi une autre offre

**Trier** :
- Prix croissant/décroissant
- Durée
- Date de soumission

### 4️⃣ Démarrer une réparation

**Quand votre offre est acceptée** :
1. ✅ Notification : "Votre offre a été acceptée !"
2. La demande apparaît avec statut **👤 Assignée**
3. Cliquez sur **"🔧 Démarrer la réparation"**
4. Le statut passe à **🔧 En cours**
5. Le client est notifié

### 5️⃣ Finaliser

1. Réparation terminée ? Cliquez sur **"✅ Finaliser la réparation"**
2. Confirmez l'action
3. Le statut passe à **✅ Terminée**
4. Le client peut également finaliser de son côté

## 🔔 Notifications

Vous recevez des notifications pour :
- ✅ Offre acceptée
- ❌ Offre rejetée automatiquement (une autre offre a été choisie)
- 🔧 Réparation démarrée
- ✅ Réparation finalisée
- ❌ Demande annulée par le client

**Types de notifications** :
- **Succès** (vert) : Action réussie
- **Erreur** (rouge) : Problème rencontré
- **Info** (bleu) : Information générale
- **Avertissement** (orange) : Attention requise

Les notifications :
- S'affichent en haut à droite
- Disparaissent automatiquement après 4 secondes
- Peuvent être fermées manuellement en cliquant dessus

## 💡 Astuces et bonnes pratiques

### Pour les clients

✅ **Soyez précis** : Plus votre description est détaillée, meilleures seront les offres
✅ **Ajoutez des photos** : Les réparateurs estiment mieux le travail
✅ **Comparez** : Utilisez le tri par prix ET durée avant de décider
✅ **Répondez vite** : Les bons réparateurs sont sollicités
✅ **Finalisez rapidement** : Dès la réparation terminée, validez

### Pour les réparateurs

✅ **Personnalisez** : Un message détaillé montre votre professionnalisme
✅ **Soyez réaliste** : Prix et durée honnêtes = clients satisfaits
✅ **Proposez une date** : Montrez votre disponibilité
✅ **Réagissez vite** : Les demandes récentes sont plus actives
✅ **Communiquez** : Tenez le client informé si besoin

---

## 🆘 Problèmes fréquents

### "Je ne peux pas annuler ma demande"
→ Une offre a déjà été acceptée. Contactez le réparateur pour discuter.

### "Je ne vois pas mes offres"
→ Vérifiez les filtres : assurez-vous de sélectionner "Toutes" dans le filtre de statut.

### "Le badge d'offres est vide"
→ Normal : aucune offre n'a encore été soumise pour cette demande.

### "La notification ne disparaît pas"
→ Cliquez dessus pour la fermer manuellement.
